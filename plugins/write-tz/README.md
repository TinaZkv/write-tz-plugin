# Плагин `write-tz`

Навык написания технических заданий (ТЗ / продуктовых спецификаций) по единому
стандарту команды.

**Что делает:** превращает бизнес-контекст + макеты в готовое к разработке ТЗ в
разметке трекера. Держит фиксированную структуру разделов, директивный блок
«Что нужно сделать», исчерпывающее описание UI-состояний, дословные тексты,
права, модалки, уведомления, онбординг, аналитику, таблицу текстов под перевод.
Недостающее уточняет у автора и подсвечивает edge cases, а не достраивает молча.

**Что НЕ делает:** не выдумывает терминологию, формат и роли продукта — берёт их
из проектного `CLAUDE.md`. Без проектного контекста соберёт только каркас.

## Состав

- `skills/write-tz/SKILL.md` — навык (форма ТЗ, правила, чек-лист).
- `skills/write-tz/mockup-explanation-template.md` — шаблон письменного пояснения
  к макету (способ B; способ A — скриншот с комментариями прямо в чат).
- `skills/write-tz/examples/` — два эталона: форма A (новая фича) и форма B
  (сквозное изменение на многих экранах).

## Установка

См. корневой `README.md` репозитория: вариант 1 — через `/plugin` (CLI), вариант
2 — копированием папки `skills/write-tz` в `~/.claude/skills/` (для десктоп-
приложения / Cowork, где `/plugin` недоступен).

## Использование

Открыть Claude Code в папке фичи (с её `CLAUDE.md` и макетами), описать задачу,
подать макеты, сказать «напиши ТЗ». Навык задаст уточняющие вопросы (включая —
нужны ли разделы «Сценарии» и «Критерии приёмки») и выдаст файл
`ТЗ_[тикет]_[краткое].md` в разметке трекера.
