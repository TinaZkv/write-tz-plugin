# Эталоны ТЗ

Два образца под две формы ТЗ (см. навык `../SKILL.md`, раздел «Две формы ТЗ»).

| Файл | Форма | Что показывает |
|---|---|---|
| `ТЗ_BA-7583_лимит-кредитов.example.md` | **A — новый объект/фича** | Структура 12 разделов, Jira wiki markup, модалка, уведомления, критерии приёмки, аналитика, таблица под перевод. Лог решений в ТЗ не выносится (только в диалоге). UI-тексты иллюстративные. |
| `[#BA-7479] … .pdf` (внутренний тикет BA — в общий репозиторий НЕ публикуется, исключён через `.gitignore`; держится локально, добавляется при необходимости) | **B — сквозное изменение** | House-эталон команды. Изменение показателя «Аудитория» на десятках поверхностей: перечень всех затронутых экранов «было → стало», ветки «если индекс A / B / вне зависимости», формула один раз + ссылки на неё, миграция пользовательских фильтров/правил при переименовании, детальный онбординг (аудитория показа, все пути закрытия, тост), явный список незатронутых отчётов. **Реальные согласованные тексты — лучший якорь, чем выдуманный пример.** |

BA-7479 также показывает структуру **объёмной задачи**: вверху краткий список
«что нужно сделать», ниже — раздел на каждый пункт (1, 1.1, 1.2 …) с описанием
макетов. Ориентир для больших ТЗ независимо от формы.

При написании нового ТЗ:
- новая сущность/экран → ориентир `ТЗ_BA-7583…` (форма A);
- меняем поведение существующего на многих экранах → ориентир BA-7479 (форма B).
