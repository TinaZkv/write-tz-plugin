# Эталоны ТЗ

Два образца под две формы ТЗ (см. навык `../SKILL.md`, раздел «Две формы ТЗ»).

| Файл | Форма | Что показывает |
|---|---|---|
| `ТЗ_BA-7583_лимит-кредитов.example.md` | **A — новый объект/фича** | Структура 12 разделов, Jira wiki markup, модалка, уведомления, критерии приёмки, аналитика, таблица под перевод. Лог решений в ТЗ не выносится (только в диалоге). UI-тексты иллюстративные. |
| `ТЗ_demo_переименование-показателя.formB.example.md` | **B — сквозное изменение** | Обезличенный демо-эталон формы B (едет в общий репозиторий). Двухуровневая структура (краткий «Что нужно сделать» + раздел на каждый пункт), ветки «если режим A / B / вне зависимости», формула один раз + ссылки, миграция пользовательских фильтров при переименовании, явный список незатронутого, сквозной онбординг. Тексты иллюстративные. |
| `[#BA-7479] … .pdf` (внутренний тикет BA — в общий репозиторий НЕ публикуется, исключён через `.gitignore`; держится локально) | **B — полный боевой эталон** | House-образец на реальных согласованных текстах: показатель «Аудитория» на десятках поверхностей. Только локально у автора. Для понимания формы B коллегам достаточно демо-примера выше и правил в `SKILL.md`. |

BA-7479 также показывает структуру **объёмной задачи**: вверху краткий список
«что нужно сделать», ниже — раздел на каждый пункт (1, 1.1, 1.2 …) с описанием
макетов. Ориентир для больших ТЗ независимо от формы.

При написании нового ТЗ:
- новая сущность/экран → ориентир `ТЗ_BA-7583…` (форма A);
- меняем поведение существующего на многих экранах → ориентир BA-7479 (форма B).
