h1. Способ расчёта показателя «Охват» и переименование фильтра

h2. Что нужно сделать

# *Добавить* в «Настройках отчётов» выбор способа расчёта «Охвата»: «Полный» или «Базовый».
# *Изменить* вывод «Охвата» в Сводке, отчёте «Темы», разделе «Сравнение» и экспортах — в зависимости от выбранного способа.
# *Переименовать* фильтр «Охват» в «Базовый охват», *добавить* фильтр «Полный охват».
# *Сделать* онбординг в Сводке — объяснить выбор и дать применить, не заходя в настройки.
# *Оставить без изменений* отчёт «Авторы» (колонка «Охват» — как сейчас).

Сквозные разделы (права, миграция, онбординг) — отдельными разделами ниже, не дублируются в пунктах.

h2. 1. Выбор способа расчёта в «Настройках отчётов»

h3. 1.1. Блок выбора

_Скриншот: блок с двумя плашками._ В «Настройках отчётов» добавляется блок «Способ расчёта охвата» с двумя плашками:
* «Полный» (выбрано по умолчанию) — подпись {{Полный охват = базовый охват + охват внешних источников}}.
* «Базовый» — подпись {{Базовый охват = охват уникальных площадок}}.

h2. 2. Вывод «Охвата» по экранам

*Формула (определяется один раз, дальше — по ссылке):*
{{Полный охват = Базовый охват + Внешний охват}}, где «Базовый охват» — сумма охватов уникальных площадок (с уникализацией по площадке), «Внешний охват» — сумма охватов внешних источников (без уникализации).

h3. 2.1. Если выбран «Полный»

_Скриншот: карточка показателя._ В Сводке, отчёте «Темы» и «Сравнении» в колонке/карточке «Охват» выводить значение по формуле из п. 2. Тултип: {{Суммарный охват площадок и внешних источников}}.

h3. 2.2. Если выбран «Базовый»

Выводить только базовый охват (как сейчас на бою). Тултип: {{Охват уникальных площадок}}.

h3. 2.3. Вне зависимости от выбора

В экспортах колонка называется «Охват»; значение считается по выбранному способу (см. 2.1/2.2).

h2. 3. Фильтр «Охват» → «Базовый охват» и новый «Полный охват»

h3. 3.1. Переименование

_Скриншот: панель фильтров._ Фильтр «Охват» переименовать в «Базовый охват»; логику не менять. Добавить «?» с тултипом {{Охват уникальных площадок}}.

h3. 3.2. Новый фильтр «Полный охват»

Добавить фильтр «Полный охват» (диапазон «от … до …»), фильтрует по значению полного охвата (формула п. 2).

h2. 4. Права доступа

Блок выбора способа расчёта и новые фильтры доступны всем ролям, которым доступны «Настройки отчётов»; новое право не вводится.

h2. 5. Миграция пользовательских объектов

У пользователей с ранее созданными персональными фильтрами, подписками и шаблонами экспорта с фильтром «Охват» после релиза он заменяется на «Базовый охват». Значения и логика сохраняются.

h2. 6. Онбординг

_Скриншот: модалка в Сводке._ Аудитория показа — существующие пользователи при заходе в Сводку; новым (созданным после релиза) не показывается. Заголовок {{Теперь охват можно считать с внешними источниками}}. Плашки выбора «Полный» (по умолчанию) / «Базовый». Пути прекращения показа: нажал «Применить» в модалке ИЛИ сохранил выбор в «Настройках отчётов». После применения — тост {{Выбран способ расчёта: [Полный/Базовый]}}.

h2. 7. Затронуто, но не меняется

Отчёт «Авторы»: колонка «Охват» (охват автора) остаётся без изменений независимо от выбранного способа расчёта.
